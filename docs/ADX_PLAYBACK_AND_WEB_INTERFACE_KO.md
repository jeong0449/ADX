# ADX의 재생 도구와 웹 인터페이스의 가능성

> **국문(Korean) 문서**

## 개요

ADX 플랫폼은 단순한 재생기가 아니라 **분석(Analyze) → 추상화(Abstract) →
교환(Exchange) → 재생(Play)** 의 전체 흐름을 지원하는 드럼 패턴 생태계를
목표로 한다.

현재는 세 개의 주요 도구가 서로 다른 역할을 담당한다.

-   **PatternLab** : MIDI 분석 및 ADX 패턴 생성
-   **ADX Player (Linux)** : ADX 패턴 재생기
-   **ADX Player for Windows** : ADX/MIDI 재생 및 콘솔 뷰어

------------------------------------------------------------------------

# PatternLab

PatternLab은 MIDI 파일에서 드럼 채널을 추출하여 패턴을 분석하고
ADT/ADP로 추상화하는 작업실이다.

주요 기능

-   RAW 연주 시각화
-   Grid(16 / 8T / 16T) 비교
-   Accent 추상화
-   Slot 변환
-   ORN 후보 검출
-   HTML 리포트 생성
-   웹 브라우저에서 즉시 재생

PatternLab은 **원본 MIDI를 이해하고 추상화하는 도구**이다.

------------------------------------------------------------------------

# ADX Player (Linux)

Linux용 플레이어는 ADX 패턴을 빠르게 검증하기 위한 경량 실행기이다.

지원

-   ADT v2.3
-   ADP v2.3
-   ORN v1.0

주 용도

-   Raspberry Pi
-   Fluid Ardule
-   반복 재생
-   명령행 자동화

즉, **pattern-only player**이다.

------------------------------------------------------------------------

# ADX Player for Windows

Windows판은 ADX뿐 아니라 일반 MIDI도 재생할 수 있는 데스크톱용
플레이어이다.

지원

-   ADT v2.3
-   ADP v2.3
-   ORN v1.0
-   Legacy ADP v2.2
-   Standard MIDI

재생 전에 ASCII 형태의 패턴을 출력하여 구조를 빠르게 확인할 수 있다.

따라서 Windows판은 **플레이어이면서 콘솔 패턴 뷰어**의 역할도 수행한다.

------------------------------------------------------------------------

# 웹 인터페이스의 가능성

PatternLab에 웹 재생 기능이 추가되면서 새로운 가능성이 열렸다.

웹 브라우저는 더 이상 보고서 뷰어가 아니라 ADX 작업 환경이 될 수 있다.

    Browser
        │
        ▼
    Local ADX Service
        │
        ├─ ADT
        ├─ ADP
        ├─ ORN
        ├─ MIDI
        └─ FluidSynth

핵심 재생 엔진은 공통 모듈로 유지하고, 웹은 사용자 인터페이스만 담당하는
구조가 바람직하다.

------------------------------------------------------------------------

# 반복 재생

웹에서 원하는 패턴을 선택하여

-   무한 반복
-   2회 반복
-   4회 반복

등을 지정할 수 있다.

SoundFont 변경도 즉시 가능하다.

------------------------------------------------------------------------

# 패턴 체인

다음 단계는 여러 패턴을 연결하는 것이다.

    Intro
     ↓
    Main A
     ↓
    Main B
     ↓
    Fill
     ↓
    Main A

사용자는 패턴을 클릭하거나 Drag & Drop하여 리듬 구조를 만들 수 있다.

------------------------------------------------------------------------

# 웹 기반 편집기

궁극적으로는 브라우저에서 직접

-   note 입력
-   accent 수정
-   subdivision 변경
-   ORN 편집

까지 가능하다.

수정 결과는 ADT로 저장하고, 필요하면 ADP를 다시 생성한다.

------------------------------------------------------------------------

# 결론

PatternLab은 **분석 도구**로,

ADX Player는 **재생 도구**로,

웹 인터페이스는 **작업 공간(workspace)** 으로 발전할 수 있다.

이러한 구조가 완성되면 ADX는 단순한 파일 포맷이 아니라,

> **분석하고, 추상화하고, 교환하고, 재생하며, 조립하고 편집하는 통합
> 드럼 패턴 플랫폼**이 된다.
